S13-00 · The KPI test

A metric reports a number. A KPI connects that number to a goal and a response.

1 · ObjectiveWhat outcome matters?

State the business goal before selecting a measure.

2 · DefinitionHow is it calculated?

Use one stable formula, grain and reporting period.

3 · ContextGood or bad compared with what?

Add a target, benchmark, prior period or trend.

4 · ActionWhat changes when it moves?

Name the owner and the decision the KPI should trigger.

Vanity or actionable?

A club tracks total app downloads. No target exists, inactive users remain in the total and no team changes a decision when the number moves.

KPI definition cardObjective + Measure + Grain + Time window + Target + Owner + Action

Example: “Increase profitable sales. Monitor monthly Profit Ratio by Segment. Target ≥ 12%. Commercial Director reviews discounts when a segment stays below target for two months.”

S13-01 · Leading and lagging indicators

Outcome measures confirm results. Driver measures create time to respond.

Leading

Signals before the outcome

Tracks behaviour or process that may influence future performance.

  • Ticket presales against pace
  • Open support backlog
  • Training attendance rate
Use for intervention
Discount policyProfit ratioDriverOutcome
Lagging

Confirms what happened

Reports the result after activity has already occurred.

  • Monthly sales
  • Season attendance
  • Year-to-date profit
Use for evaluation

Early-warning check

The goal is to reach the season-ticket target before opening day. Which indicator gives the team more time to act?

Do not call every predictor a leading KPI

A useful leading indicator needs evidence or a credible operating link to the outcome. Review that relationship over time.

TiledDefault for structure

Objects resize together and keep reliable alignment.

HorizontalRow of peers

KPI cards, filters or charts with equal visual rank.

VerticalReading sequence

Title, KPI strip, analysis and supporting detail.

FloatingUse sparingly

Legends, overlays or controls that must sit above the grid.

Container logic

Four KPI cards must stay equal width when the dashboard resizes. What is the most robust setup?

Layout rules that prevent rework
  1. Set a deliberate dashboard size before arranging content.
  2. Build the outer vertical structure first.
  3. Nest horizontal containers only where objects share a row.
  4. Use padding for rhythm instead of blank objects.
  5. Check the hierarchy at 50% zoom. Status should read before diagnosis.

S13-06 · Guided executive dashboard lab

Build a decision route from status to diagnosis.

Business brief

Regional commercial performance

The Commercial Director needs to monitor Sales, Profit Ratio and Orders, identify weak regions, then inspect the categories responsible.

Audience

Commercial Director

Cadence

Monthly review

Action

Adjust discount and category focus

1

Define the KPIs

Create Sales, Profit Ratio and COUNTD(Order ID). Document the reporting period and comparison.

Calculated fields
// Profit Ratio
SUM([Profit]) / SUM([Sales])

// Order Count
COUNTD([Order ID])
2

Build the header

Create one KPI sheet per measure. Add current value, YoY delta and a compact 12-month trend.

Quality check

Use consistent number formats. State whether change is percent or percentage points. Keep colour for status.

3

Add diagnosis

Build a monthly trend and a Region × Category profit highlight table.

Why these views?

The trend reveals when performance changed. The grid reveals where losses concentrate.

4

Structure the canvas

Use one outer vertical container, a horizontal KPI strip and a horizontal analysis row.

Container tree
Dashboard
└── Vertical container
    ├── Title + controls
    ├── Horizontal KPI strip
    └── Horizontal analysis row
5

Add interaction

Use Region as a filter action. Add a reset route and a show/hide definition panel.

Interaction test

Select, clear and switch regions. Titles, KPI values and detail views must communicate the active state.

6

Validate the system

Check totals against a worksheet, test empty selections and record load time.

Acceptance criteria
  • The KPI definition is visible or one click away.
  • Every colour has a stated rule.
  • One interaction reveals the weak category.
  • The dashboard remains readable at delivery size.

Final knowledge check

A metric has no target, owner or decision response.

2 · Context

Executives need actual performance against a fixed target.
