S12-00 · Opening chart clinic

The most advanced chart is the one that makes the right comparison easy.

Where?Geographic pattern

Use a map only when location is part of the explanation.

How spread?Distribution

Use a boxplot to expose median, variation and outliers.

Related?Relationship

Use a scatter plot to compare two measures at a meaningful grain.

Who moved?Rank or change

Use bump, slope or dumbbell according to the comparison.

What pattern?Two-dimensional grid

Use a highlight table to scan intersections quickly.

Commit before continuing

You need to compare profit in 2020 versus 2021 for eight sub-categories and emphasise direction of change. Which chart is the cleanest fit?

The professional test

Before building, say what one mark represents, what comparison the viewer must make and what decision the view should support.

S12-01 · Advanced maps

A map earns its place when geography explains the pattern.

Symbol map

Compare magnitude fairly

Size = Sales. Colour = Profit Ratio. State area does not distort magnitude.

Best use

Totals, counts and dual encoding across a manageable number of locations.

Filled map

Compare rates by region

Colour = Profit Ratio, Return Rate or Growth %. One value per geographic area.

Best use

Rates, percentages and proportions when the regional shapes are recognisable.

QuantitySize

Sales, orders, customers.

QualityColour

Margin, rate, performance.

ContextLight background

Keep only useful boundaries.

InteractionHighlight + tooltip

Search without filter clutter.

Encoding check

A state has very high sales but negative profit. Which professional encoding reveals both facts?

Hands-on 1 · Superstore

Build a state performance map

  1. Double-click State; confirm its geographic role.
  2. Choose Circle marks.
  3. Drag Sales to Size.
  4. Create Profit Ratio = SUM([Profit]) / SUM([Sales]).
  5. Drag Profit Ratio to Colour; centre a colour-blind-safe diverging palette on 0.
  6. Keep State, Sales, Profit and Profit Ratio in a concise tooltip.

S12-02 · Distribution and boxplots

An average hides the shape of the data.

Typical lowMiddle 50%MedianTypical highOutlier

Read in this order

  1. Median: where is the typical observation?
  2. IQR: how variable is the middle half?
  3. Whiskers: how far does the typical range extend?
  4. Outliers: which observations need explanation?

In Tableau, default whiskers commonly extend to 1.5 × IQR. A point beyond them is unusual, not automatically wrong.

Interpret, do not merely identify

Technology has a higher median order profit but a much taller box than Office Supplies. What can you safely conclude?

Hands-on 2 · Superstore

Compare order-profit distributions

  1. Create Order Profit = { FIXED [Order ID] : SUM([Profit]) }.
  2. Place Category on Columns and Order Profit on Rows.
  3. Place Order ID on Detail so each mark is an order.
  4. From Analytics, add a Box Plot.
  5. Inspect the most extreme negative outliers.
Explain before revealing

Which category has the highest median? Which is most variable? Is the strongest outlier an error, a rare loss or a strategically important order?

Why an order-level LOD?

Superstore contains product lines. The LOD prevents multi-line orders from being treated as separate observations.

Five-minute reset

You can now locate a pattern and describe its distribution. Next: test relationships and movement.

S12-03 · Scatter plots and trendlines

A scatter plot is only as meaningful as the grain of each dot.

Sales →Profit →
1Direction

Positive, negative or no clear relationship?

2Strength

How tightly do marks follow the pattern?

3Clusters

Do meaningful groups occupy different zones?

4Outliers

Which dots break the pattern, and why?

Grain check

You drag Sales to Columns and Profit to Rows. Tableau shows one dot. What is missing?

LinearStraight direction

Start here when the relationship is plausibly constant.

SlopeRate of change

Positive rises; negative falls. Units matter.

R²Fit, not truth

Closer to 1 means the model explains more observed variation.

CautionCorrelation ≠ causation

A fitted pattern does not prove one variable causes the other.

Hands-on 3 · Superstore

Find high-sales, low-profit customers

  1. Sales → Columns; Profit → Rows.
  2. Customer Name → Detail; Segment → Colour.
  3. Add a linear trendline from Analytics.
  4. Add median reference lines to create four quadrants.
  5. Label only strategically important outliers.
Write the insight

Complete: “Customers show a ___ relationship between sales and profit, but ___ sits in the high-sales/low-profit quadrant and should be investigated for ___.”

Trendline discipline

Read direction and R², inspect outliers, and avoid causal language. Compare by Segment only if separate lines remain useful.

S12-04 · Ranking and comparison charts

Choose from the structure of change, not from visual novelty.

Bump

Rank across 3+ periods

Who rises, falls or remains stable?

Slope

One measure, two points

Who improved or declined, and by how much?

Dumbbell

Two values per category

Where is the gap largest?

Chart selector

You want to show how Category rank changes each year from 2018 to 2021. Absolute Sales is secondary.

Hands-on 4 · Superstore

Build a category bump chart

  1. Discrete Year of Order Date → Columns.
  2. Sales → Rows; Category → Colour and Detail.
  3. Apply Quick Table Calculation → Rank.
  4. Edit: address Category, partition by Year.
  5. Reverse the axis so rank 1 is at the top.
  6. Label line ends, not every mark.
Debugging test

Within every year, ranks must restart at 1. If they run continuously across time, addressing and partitioning are wrong.

Alternative: slope chart

Filter to exactly two years, return to Sales rather than Rank, use thin lines and label only start and end values.

S12-07 · Decision check

Select the chart from the comparison the audience must make.

Where?Map

Only if geography explains the result.

Spread?Boxplot

Median, variability and unusual cases.

Related?Scatter

Two measures at a declared grain.

Rank movement?Bump

Positions across several periods.

Two-point change?Slope / dumbbell

Direction or gap between two values.

Grid pattern?Highlight table

Scan two dimensions efficiently.

Exit ticket

  4. When would you choose a slope chart instead of a bump chart?
